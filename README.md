# Model-PaintJob-Display
## Goal
Make a webapp that displays the various methods and paints used for model painting.
Things that I want to implement:
1. create 3d models
2. load 3d models
3. apply paint on 3d models (with possible methods i.e. drybrushing, glazing, etc.)
## Topics that will be applied in this project:
- 3D modeling
- Webdesign
- server hosting for webpages
- understanding of:
    1. HTML/ Handlebars
    2. Javascript
    3. CSS and styling 
- UI design
## Libraries used:
- three.js
- node.js
